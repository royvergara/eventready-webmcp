DEVEventReady for agents

WebMCP implementation

The event workspace people and agents can plan together.

EventReady keeps guests, vendors, budget, ownership, and the day-of schedule in one visible event model. WebMCP lets an agent understand and update that same plan.

How it uses WebMCP9 site tools

An agent can read the event brief, assess readiness, inspect unresolved work, select a provider plan, change service level, confirm assumptions, assign responsibilities, and produce the run-of-show.

Every call operates on the same EventSession the consumer interface renders. Human decisions remain visible and reviewable; tools never place orders or silently accept commitments.
